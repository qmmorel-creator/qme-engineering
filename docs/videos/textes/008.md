# 008 · CRM freelance · par qui commencer aujourd'hui ?

Produit : CRM · Type : interface · Durée : DUREE s

## LinkedIn

Ce matin, cinq relances à faire. Par laquelle commencer ?

Dans le CRM freelance, la réponse tient en trois écrans :

▪ Aujourd'hui : la liste de qui relancer, les retards en tête ;
▪ Factures, filtre « En retard » : le montant dû, et à qui ;
▪ Chiffres : le poids de ce client dans votre chiffre d'affaires.

Le même nom revient sur les trois écrans : c'est votre priorité du jour.

Ce n'est pas un logiciel de facturation : vos factures restent faites avec votre outil, le CRM en suit le paiement. Achat unique, sans abonnement.
