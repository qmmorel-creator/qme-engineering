# 003 · 8 chapitres ajoutés d'un coup : tout tombe le même jour ?
Produit : REV · Type : démonstration · Durée : 33 s

## LinkedIn

Avant les partiels de décembre, on rattrape souvent plusieurs chapitres à la fois. Les noter un par un décourage ; les noter tous d'un coup fait craindre une journée de révision impossible à tenir.

Dans le Planning de révision, la saisie se fait en une fois :

▪ un chapitre par ligne, dans une seule fenêtre ;
▪ la première révision de chacun est placée au lendemain ;
▪ au-delà de 8 révisions par jour (réglable), les suivantes passent au jour d'après.

La vidéo montre huit chapitres de philosophie ajoutés d'un coup. Le lundi passe de 2 à 8 révisions, le maximum ; les 2 chapitres restants sont placés le mardi, visibles en un clic dans le détail du jour.

Données fictives.
