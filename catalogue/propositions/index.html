Propositions commerciales

Pour les freelances, consultants, formateurs et petites agences qui répondent à une demande : une proposition claire, trois options, une réponse. Rédigez en une heure une proposition structurée, présentez-la dans un PDF soigné, puis suivez-la jusqu'à la signature.

Quelle différence avec un devis ?

La proposition explique le projet : votre compréhension du besoin, les objectifs, les livrables, votre méthode, les options et le calendrier. Elle affiche des prix hors taxes. Le devis, établi une fois l'option choisie, chiffre ligne à ligne avec la TVA et les mentions obligatoires : c'est le rôle du Générateur de devis. Les deux se complètent.

Pourquoi trois options ?

Une seule offre appelle un oui ou un non ; trois options font choisir entre plusieurs oui. Chaque trame propose une gamme type (essentiel, confort, premium) dont chaque niveau reprend le précédent. Vous fixez vos prix, marquez l'option que vous recommandez, et le tableau de comparaison se construit seul. Le suivi vous montre ensuite quelle option vos clients retiennent.

Les mentions légales sont-elles incluses ?

Non, volontairement : une proposition commerciale n'est pas un document de facturation. Aucun taux de TVA ni aucune mention obligatoire n'est intégré. Si vous le souhaitez, vous saisissez vous-même un taux pour afficher aussi les prix TTC. Les mentions obligatoires figurent dans le devis ou la facture.

Comment fonctionnent les relances ?

Quand vous marquez une proposition comme envoyée, sa date de validité et la date de la prochaine relance sont calculées (intervalle réglable, 7 jours par défaut). Le jour venu, elle passe « à relancer » ; un message de relance prêt à copier est proposé. Rien n'est envoyé à votre place. Une validité dépassée se prolonge en un clic.

Comment est calculé le taux de transformation ?

Sur les 12 derniers mois, les propositions acceptées divisées par les propositions tranchées (acceptées, refusées ou classées sans suite). Il est aussi donné en valeur : le montant des options retenues sur le montant des propositions tranchées. Le suivi ajoute le délai moyen de réponse, l'option la plus choisie, les motifs de refus et le détail par trame.
